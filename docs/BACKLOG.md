# Feature Backlog

Features that aren't a roadmap stage. Pick one per feature session: copy
`docs/features/_TEMPLATE.md` to `docs/features/<name>.md`, fill it in, then run
`/session-start <name>`.

Status: `idea` → `ready` (brief written) → `in progress` → `done`.
